# CalyzaTech — The Calyza Crystal (PRD)

## Original Problem Statement
Build the first production-quality frontend foundation for a completely new CalyzaTech website. Core concept: THE CALYZA CRYSTAL IS THE WEBSITE — a central interactive, faceted optical crystal (React Three Fiber + Drei, procedural) that expands like an atom on scroll, revealing internal rings, layers, pathways and nodes across 6 scroll states (Origin, Opening, Inside, Ecosystem, Acceleration, AI Factory). Minimal ivory/lavender environment, Fraunces + Inter typography, quiet navigation with "Enter AI Factory" CTA, AI Factory with exactly four industries (Healthcare, FinTech, Education, Hospitality — NO Manufacturing/Retail), tagline "Industry-ready intelligence, built to deploy.", CSS/SVG fallback before 3D init, reduced-motion + performance safeguards, reusable component architecture, data separated from presentation. Do NOT build full Services/Case Studies/Contact pages or partner ecosystem yet. Stop after the foundation.

## User Personas
- Prospective enterprise client (Healthcare/FinTech/Education/Hospitality) evaluating CalyzaTech's credibility and craft.
- Design/brand reviewers judging the crystal-first identity.

## Architecture
- Frontend: React 19 + craco, React Three Fiber 9 + drei 10 + three 0.185 (procedural crystal: MeshTransmissionMaterial core, wireframe inner shells, 3 orbital rings, 8 nodes), framer-motion (reveals), lenis (smooth scroll).
- Backend: FastAPI, single custom endpoint POST /api/contact (MongoDB collection `contact_messages`), template status endpoints retained.
- Key components: CrystalScene / CrystalCanvas / CrystalObject / CrystalFallback / CrystalController / CrystalScrollProgress / CrystalChapter / Hero / Marquee / AIFactoryPreview / AIFactorySection / IndustryPanel / Navigation / ContactFooter / SmoothScroll. All content in src/data/content.js.
